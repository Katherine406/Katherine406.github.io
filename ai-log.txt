Vibe Coding Process: AI & Tools Reflection

We adopted an AI-assisted Vibe coding process to accelerate the iteration speed. Our main tools include those for implementing HTML/CSS/JavaScript, GitHub Pages for deployment, Figma for prototype design, and AI coding support in Cursor for quick editing, rewriting, and structural reorganization.

How AI was used
- Drafting and polishing portfolio text sections.
- Refactoring page structure and navigation flow.
- Rapidly testing alternative timeline layouts and jump interactions.
- Converting raw testing notes into structured evaluation content.

What worked
- Fast iteration on layout and wording reduced production time.
- AI helped quickly generate multiple phrasing options for academic sections.
- Modular edits (section-by-section updates) improved maintainability.
- User-testing summaries became clearer after AI-assisted restructuring.

What didn’t work
- Some generated UI ideas looked visually inconsistent and required manual redesign.
- AI-proposed style changes occasionally conflicted with existing CSS structure.
- Auto-generated wording was sometimes too generic and needed domain-specific rewriting.
- Performance/usability issues (e.g., image loading and hosting stability on GitHub Pages) still required manual technical fixes.

Reflection for next iteration
AI is highly effective for speed, drafting, and refactoring, but design quality still depends on human judgment, testing evidence, and final editorial control.
In future iterations, we plan to define stricter style tokens and component rules earlier to reduce rework.
