Vibe Coding Process: AI & Tools Reflection

We adopted an AI-assisted Vibe coding process to accelerate the iteration speed. Our main tools include those for implementing HTML/CSS/JavaScript, GitHub Pages for deployment, Figma for prototype design, and AI coding support in Cursor for quick editing, rewriting, and structural reorganization.

How AI was used
- Drafting and polishing portfolio text sections.
- Refactoring page structure and navigation flow.
- Rapidly testing alternative timeline layouts and jump interactions.
- Converting raw testing notes into structured evaluation content.

What worked
- Fast iteration on layout and wording reduced production time.
- AI helped quickly generate multiple phrasing options for academic sections.
- Modular edits (section-by-section updates) improved maintainability.
- User-testing summaries became clearer after AI-assisted restructuring.

What didn’t work
- Some generated UI ideas looked visually inconsistent and required manual redesign.
- AI-proposed style changes occasionally conflicted with existing CSS structure.
- Auto-generated wording was sometimes too generic and needed domain-specific rewriting.
- Performance/usability issues (e.g., image loading and hosting stability on GitHub Pages) still required manual technical fixes.

Reflection for next iteration
AI is highly effective for speed, drafting, and refactoring, but design quality still depends on human judgment, testing evidence, and final editorial control.
In future iterations, we plan to define stricter style tokens and component rules earlier to reduce rework.

AI Prompts
1. Project Direction
“Help us define the core problem, target users, and value proposition for a campus navigation app for XJTLU freshmen and visitors.”

2. Feature Prioritization
“Create a Must/Should/Could feature list for our UniBuddy project based on human-centered design principles.”

3. Interview Analysis
“Summarize our interview notes into key pain points and map them into design opportunities.”

4. Questionnaire Insights
“Turn our questionnaire results into 3 key strengths and 3 critical gaps of current campus navigation tools.”

5. Gap Analysis
“Compare official campus map apps and social discovery apps, and explain where UniBuddy can create unique value.”

6. Persona Writing
“Generate two personas (freshman and external visitor) with goals, frustrations, and realistic campus scenarios.”

7. Feature Mapping
“Map persona pain points to product features using ‘Insight → Opportunity → Solution’ format.”

8. User Journey
“Draft a user journey map for first-week campus exploration and highlight the biggest friction points.”

9.Prototype Iteration
“Suggest three prototype directions and explain why one should be selected after usability testing.”

10. Pilot Test Interpretation
“Help us write a clear summary of pilot test strengths, weaknesses, and design improvements.”

11.SUS Reflection
“Based on our SUS score, write a short reflection with realistic next-step improvements.”

12. Technical Reflection
“Write a student-style technical reflection about trade-offs between innovation, stability, and usability.”

13.Ethical Discussion

14. Frontend Refinement
